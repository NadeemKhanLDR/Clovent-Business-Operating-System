# 06.01 Coding Standards & Design Patterns

## Core Principles

1. **SOLID Principles**: Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, Dependency Inversion.
2. **Thin CLI Shell**: All business generation logic resides inside `Clovent.Generator` and `Clovent.Core`, never inside CLI command handlers.
3. **Strongly-Typed IDs**: Entities use strongly-typed record structs (e.g., `OrderId(Guid Value)`).
4. **Immutability & Encapsulation**: Domain entities mutate state only through explicit factory methods and methods, exposing private setters.
5. **CQRS**: Commands for write operations, Queries for read operations handled via MediatR handlers.
6. **Zero Warning & Zero Error Compilation**: All solution builds must pass cleanly with 0 warnings and 0 errors.
