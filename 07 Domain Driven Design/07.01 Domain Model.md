# 07.01 Domain-Driven Design (DDD) Standards

## Tactical DDD Patterns

- **Aggregate Root**: Extends `AggregateRoot<TId>` base class, manages invariants and publishes domain events via `AddDomainEvent`.
- **Entities**: Domain concepts with distinct identities.
- **Value Objects**: Immutable objects identified by their attributes (e.g. Strongly-typed IDs, Money, Address).
- **Domain Events**: Dispatched upon state changes to notify other aggregates or bounded contexts.
