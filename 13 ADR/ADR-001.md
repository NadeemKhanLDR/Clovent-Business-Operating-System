# ADR-001: Adopt Clean Architecture and Modular Vertical Slice in CBOS

## Context
CBOS requires a scalable architecture for WinForms + DevExpress enterprise applications supporting modular development, code generation, and automated documentation.

## Decision
We adopt Clean Architecture with Vertical Slice modularization:
- Logic decoupled from UI and CLI shells.
- Business generation logic encapsulated inside `Clovent.Generator`.
- Infrastructure decoupled via EF Core mappings and Dependency Injection.

## Consequences
- Clean separation of concerns.
- High testability across domain, application, generator, and CLI layers.
